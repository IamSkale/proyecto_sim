## 🎯 Orden del Problema Asignado

**Problema #2: Puerto Sobrecargado (Overloaded Harbor)**

Se desea simular el funcionamiento de un puerto de supertanqueros que cuenta con:
- **3 muelles** para la descarga de barcos
- **1 remolcador** para asistir a los tanqueros en su aproximación y salida de los muelles

**Objetivo principal:** Determinar el **tiempo promedio de espera de los barcos** para ser cargados en el puerto.
